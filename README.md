## 🚀 Featured Projects

### 💼 Hirevia – Remote Job Platform

A full-stack remote job platform connecting candidates and companies.

**Tech Stack:** React.js, Vite, JavaScript, Tailwind CSS, Node.js, Express.js, MongoDB

**Key Features:**

- 🔐 JWT-based authentication
- 👥 Role-based authorization for Candidate, Company and Admin
- 🔎 Job search and filtering
- 📄 Resume upload
- 📑 Job applications and application tracking
- 📊 Pagination
- 🔔 Notifications
- 👤 Candidate and company profiles
- 🛠️ Admin operations
- 🔄 CRUD operations
- 🌐 REST APIs
